# 环境健康统计建模工作台

这是一个基于本科毕业论文建模样本搭建的统计实证研究工作台。项目围绕“空气污染与呼吸系统健康负担的统计关联”展开，覆盖数据诊断、描述性统计、趋势分析、相关性分析、面板回归、稳健性检验、主成分分析和区域异质性分析。

项目定位是一个可继续扩展的统计学科研训练工具，而不是某个具体平台的申请演示。它可以用于本科论文复盘、研究生入学前的统计建模训练、课程展示、科研方法学习和后续实证研究拓展。

## 主要功能

1. 数据概览：自动展示观测数、字段数、省份数、年份范围、区域分布和缺失值情况。
2. 趋势分析：展示健康负担代理指标与主要污染物的年度变化。
3. 相关性分析：计算变量相关矩阵，辅助识别多污染物共线性问题。
4. 模型实验室：支持混合 OLS、双向固定效应和区域异质性交互项模型。
5. 稳健性检验：支持切换基准因变量、住院率和两周就诊率。
6. PCA 分析：将多个污染物压缩为综合污染因子，检验多污染物共线性下的结果稳定性。
7. 异质性分析：比较东部地区与非东部地区在污染物相关关系上的差异。
8. 报告辅助：生成论文结果分析模板，帮助把统计结果转化为规范表述。

## 推荐运行环境

建议使用 Python 3.11。你可以保留电脑里的旧 Python，不需要卸载旧版本。

## 安装与运行

进入项目文件夹：

```cmd
cd /d D:\Desktop\environment_health_panel_workbench
```

创建虚拟环境：

```cmd
py -3.11 -m venv .venv
.venv\Scripts\activate
```

安装依赖：

```cmd
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

先运行自动分析：

```cmd
python analysis_pipeline.py
```

再启动网页应用：

```cmd
python -m streamlit run app.py
```

如果浏览器没有自动打开，手动访问：

```text
http://localhost:8501
```

## 后续可扩展方向

1. 增加 Hausman 检验、VIF 检验和残差诊断模块。
2. 增加空间面板模型或空间相关性探索。
3. 增加时间序列滞后项和分布滞后模型。
4. 增加更多稳健性检验，例如更换控制变量、剔除特殊地区、缩尾处理等。
5. 增加研究报告自动导出为 Word 或 PDF 的功能。
6. 后续可以接入任意大语言模型 API 或本地模型，用于自动解释统计结果、生成答辩问题和优化论文表述。
