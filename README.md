# 环境健康统计建模工作台

这是一个基于本科毕业论文真实建模样本搭建的统计实证研究工作台。项目围绕“空气污染与呼吸系统健康负担的统计关联”展开，覆盖数据诊断、描述性统计、趋势分析、相关性分析、面板回归、稳健性检验、主成分分析和区域异质性分析等流程。

本项目定位为一个可持续扩展的统计学科研训练工具，可用于本科论文复盘、研究生入学前统计建模训练、课程展示、科研方法学习和后续实证研究拓展。

## 项目背景

本人本科毕业论文题目为《空气污染对呼吸系统疾病影响的多元回归分析》。论文基于中国 31 个省级行政区 2018—2022 年省级年度面板数据，研究 PM2.5、PM10、SO2、NO2、O3 等空气污染变量与呼吸系统健康负担代理指标之间的统计关系。

在论文基础上，本项目进一步将原本分散在数据表、代码脚本、回归结果和论文文本中的分析流程整理为可交互的网页工作台，便于复现、展示和继续扩展。

## 主要功能

1. 数据概览：自动展示观测数、字段数、省份数、年份范围、区域分布和缺失值情况。
2. 描述性统计：展示核心变量的均值、标准差、最小值和最大值。
3. 趋势分析：展示主要污染物随年份变化的趋势。
4. 相关性分析：生成污染物变量和控制变量之间的相关性矩阵。
5. 回归建模：支持 OLS 回归和双向固定效应模型。
6. 稳健性检验：支持替换因变量后的模型比较。
7. 主成分分析：对多类污染物进行 PCA 降维，缓解多重共线性问题。
8. 区域异质性分析：比较不同区域中污染物变量与健康负担指标之间的统计差异。
9. 自动研究报告：将数据概况、描述性统计、相关性结果和研究解释整理为 Markdown 报告。
10. 智能研究助手：生成面向论文写作和答辩准备的结构化解释材料。

## 数据说明

本项目使用的是本人本科毕业论文阶段整理的建模样本数据。数据为省级年度面板结构，观测对象为中国 31 个省级行政区，时间范围为 2018—2022 年。

核心变量包括：

- 呼吸系统健康负担代理指标
- PM2.5
- PM10
- SO2
- NO2
- O3
- 人口规模
- 人均 GDP
- 城镇化率
- 第二产业占比
- 医疗资源变量
- 区域变量
